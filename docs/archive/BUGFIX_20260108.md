### 원인 1: numpy.int64 → BLOB 타입 저장

**위치**: [database_manager.py:1239-1240](db/database_manager.py#L1239-L1240)

**결과**:

- 중복 매도 검사 쿼리 `WHERE buy_record_id = ?`가 매칭 실패
- BLOB ≠ INTEGER 비교로 항상 0건 반환

### 3. 기존 오염된 데이터 정리

**실행 내역**:
