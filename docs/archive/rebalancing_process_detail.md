# 리밸런싱 과정 상세 설명

## 📋 개요

리밸런싱 시스템은 매일 자동으로 실행되어 포트폴리오를 최적화합니다. 매일 값들을 갱신하고, 종목별 점수와 예상 수익률을 재계산하여 목표 포트폴리오를 구성합니다.

---

## 🔄 일일 리밸런싱 프로세스

### 1단계: 매일 15:40 - 퀀트 스크리닝 실행

**목적**: 전체 종목을 평가하여 상위 50개 종목 선정

**과정**:

1. **전체 종목 필터링** (1차 필터링)
   - 시가총액 ≥ 1,000억원
   - 최근 20일 일평균 거래대금 ≥ 10억원
   - 주가 범위: 1,000원 ~ 500,000원
   - 상장 ≥ 250 거래일
   - 재무데이터 존재 확인

2. **팩터 점수 계산** (매일 갱신)
   각 종목에 대해 4개 팩터 점수를 **매일 새로 계산**합니다:
   
   - **Value 팩터 (30%)**: PER, PBR, PSR 점수화
   - **Momentum 팩터 (30%)**: 1M/3M/6M/12M 수익률, RSI(14)
   - **Quality 팩터 (20%)**: ROE, ROA, 부채비율, 유동비율, 영업이익률
   - **Growth 팩터 (20%)**: 매출 성장률, 순이익 성장률, EPS 성장률

3. **최종 점수 계산**
   ```
   최종 점수 = Value(30%) + Momentum(30%) + Quality(20%) + Growth(20%)
   ```

4. **상위 50개 선정 및 저장**
   - 점수 순으로 정렬
   - 상위 50개 종목을 `quant_portfolio` 테이블에 저장
   - 각 종목의 점수, 순위, 팩터별 점수 저장

**중요**: 매일 새로운 데이터로 점수를 재계산하므로, 종목의 순위와 점수가 **매일 변경**됩니다.

---

### 2단계: 익일 09:05 - 리밸런싱 실행

**목적**: 현재 보유 종목을 목표 포트폴리오와 비교하여 매도/매수 결정

**과정**:

1. **현재 보유 종목 조회**
   - 계좌에서 실제 보유 종목과 수량 조회

2. **목표 포트폴리오 조회**
   - 전날 15:40에 생성된 포트폴리오 사용
   - 예: 12/12 09:05 리밸런싱 → 12/11 15:40 포트폴리오 사용

3. **리밸런싱 계획 계산**
   - **매도 대상**: 보유 중이지만 목표 포트에 없는 종목
   - **매수 대상**: 목표 포트에 있지만 보유하지 않은 종목
   - **유지 대상**: 양쪽에 모두 있는 종목

4. **매도 실행** (시장가 전량)
   - 매도 대상 종목을 시장가로 전량 매도

5. **매수 실행** (동등 비중, 시장가)
   - 매수 대상 종목을 동등 비중으로 매수
   - 총 자금을 종목 수로 나눠서 각 종목당 투자 금액 계산
   - 예: 총 자금 1,000만원, 50개 종목 → 종목당 20만원

## 📊 매일 값 갱신 메커니즘

### 1. 팩터 점수 갱신

매일 15:40 스크리닝 시점에 **모든 종목의 팩터 점수를 재계산**합니다:

- **Value 팩터**: 최신 재무 데이터 반영
- **Momentum 팩터**: 최신 가격 데이터로 수익률 재계산
- **Quality 팩터**: 최신 재무제표 데이터 반영
- **Growth 팩터**: 최신 성장률 데이터 반영

**결과**: 종목의 점수가 매일 변경되므로, 순위도 매일 변경됩니다.

### 2. 포트폴리오 순위 변경

매일 점수가 갱신되면:
- 어제 상위 50개였던 종목이 오늘은 51위로 밀려날 수 있음
- 어제 51위였던 종목이 오늘은 상위 50개에 진입할 수 있음

**예시**:
```
12/11 15:40 스크리닝:
  1위: 종목A (점수 85.0)
  2위: 종목B (점수 82.5)
  ...
  50위: 종목Z (점수 60.0)
  51위: 종목AA (점수 59.5)

12/12 15:40 스크리닝 (새로운 데이터로 재계산):
  1위: 종목B (점수 87.0) ← 점수 상승
  2위: 종목A (점수 84.0) ← 점수 하락
  ...
  50위: 종목AA (점수 61.0) ← 51위에서 50위로 진입
  51위: 종목Z (점수 59.0) ← 50위에서 51위로 하락
```

## 🎯 목표 수익률 및 손익비

### 1. 매수 시점

리밸런싱으로 매수할 때는 **동등 비중**으로 매수합니다.

### 2. 장중 매도 판단

매수 후 장중 매도 판단 시에는 `trading_config.json`의 설정값을 사용합니다:

- **익절 기준**: `risk_management.take_profit_ratio` (기본값: 15%)
- **손절 기준**: `risk_management.stop_loss_ratio` (기본값: 10%)

모든 종목에 동일한 기준이 적용됩니다.

---

### 3. 종목별 예상 수익률 변경

**현재 구현 상태**: 리밸런싱 자체에서는 종목별 목표 수익률을 직접 변경하지 않습니다.

**하지만 간접적으로 영향**:
1. **점수 상승 종목**: 더 높은 점수 → 더 높은 순위 → 포트폴리오에 포함
2. **점수 하락 종목**: 낮은 점수 → 낮은 순위 → 포트폴리오에서 제외

**예시**:
```
종목A: 12/11 점수 60.0 (50위) → 12/12 점수 75.0 (20위)
  → 점수 상승 → 더 높은 순위 → 포트폴리오 유지

종목B: 12/11 점수 65.0 (45위) → 12/12 점수 55.0 (55위)
  → 점수 하락 → 낮은 순위 → 포트폴리오에서 제외
  → 리밸런싱 시 매도 대상
```

## 🔍 핵심 포인트

### 1. 매일 값 갱신
- ✅ **팩터 점수**: 매일 15:40에 모든 종목 재계산
- ✅ **포트폴리오 순위**: 매일 변경됨
- ✅ **목표 포트폴리오**: 매일 새로 생성됨

### 2. 목표 수익률 및 손익비
- ✅ **매수 시점**: 동등 비중
- ✅ **장중 매도 판단**: `trading_config.json`의 설정값 사용
  - 익절: `take_profit_ratio` (기본 15%)
  - 손절: `stop_loss_ratio` (기본 10%)
- ✅ **모든 종목 동일 기준 적용**

### 3. 종목별 예상 수익률
- ✅ **간접적 영향**: 점수 상승 → 더 높은 순위 → 포트폴리오 유지
- ⚠️ **직접적 변경 없음**: 리밸런싱에서 종목별 목표 수익률을 직접 변경하는 로직은 없음

---

## 💡 개선 가능한 부분

현재 시스템에서 **종목별 목표 수익률을 리밸런싱 시점에 직접 변경**하는 기능은 없습니다.

**추가 가능한 기능**:
1. **점수 기반 목표 수익률**: 점수가 높은 종목은 더 높은 목표 수익률 설정
2. **팩터별 목표 수익률**: Momentum 점수가 높으면 더 높은 목표 수익률
3. **순위 기반 목표 수익률**: 상위 10위 종목은 더 높은 목표 수익률

이러한 기능을 추가하려면 `core/quant/quant_rebalancing_service.py`의 `execute_rebalancing` 메서드를 수정하여 매수 시점에 종목별 목표 수익률을 설정하는 로직을 추가해야 합니다.
