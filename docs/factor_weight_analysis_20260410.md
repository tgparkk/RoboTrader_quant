## 7. 전문가 토론 요약

### 통계 전문가
- 3회 실행에서 1위 조합이 모두 다름 → 과적합 신호
- Calmar 비율(연수익/MDD): 현행 25.99 > 세밀1위 18.90 → 리스크 조정 시 현행 우위
- 보수적 대안으로 V25/M30/Q22/G22 추천

### 시스템 아키텍트
- "깨진 공식 위에서 가중치 최적화 = 노이즈 피팅"
- 공식 수정 → 재멀티버스 → 가중치 확정 순서 권고
- hybrid_score 희석 (가중치 변경 효과가 라이브에서 50%로 감쇠)

### 비평 전문가 (REJECT → REVISE)
- 샤프와 거래 수 상관 r=0.67 → 거래 빈도가 샤프를 부풀림
- MDD 16%→29% (2배)는 실전에서 감당 어려움
- score_momentum 필터가 멀티버스에 미반영

### 합의
Growth 버그 수정만 먼저 적용, 가중치 변경은 2~4주 관찰 후 재검토
