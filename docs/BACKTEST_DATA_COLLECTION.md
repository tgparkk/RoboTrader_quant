# 백테스팅용 데이터 수집 전략

## 📋 개요

백테스팅의 정확성을 위해 **각 시점에서 실제로 알 수 있었던 데이터만** 수집하도록 시스템을 수정했습니다.

**핵심 원칙**: T일에는 T-1일(전 영업일)까지의 데이터만 수집

**파일**: `utils/korean_time.py`

```python
def get_previous_trading_day(dt: datetime = None, market: str = 'KRX') -> datetime:
    """전 영업일 반환 (주말, 공휴일 자동 건너뛰기)
    
    Examples:
        >>> # 2025-12-26(목) → 2025-12-25(수)
        >>> get_previous_trading_day(datetime(2025, 12, 26))
        datetime(2025, 12, 25, 0, 0, 0)
        
        >>> # 2025-12-23(월) → 2025-12-20(금) (주말 건너뛰기)

        datetime(2025, 12, 20, 0, 0, 0)
    """
```

**기능**:
- 주말(토, 일) 자동 건너뛰기

- 향후 공휴일 캘린더 추가 가능

## 🔍 백테스팅 검증 쿼리

### 1. 일자별 데이터 수집 확인
```sql
-- 12월 전체 일봉 데이터 확인
SELECT 
    date,
    COUNT(DISTINCT stock_code) as stock_count,
    MIN(close) as min_price,
    MAX(close) as max_price
FROM daily_prices
WHERE date >= '2024-12-01'
GROUP BY date
ORDER BY date;

-- 예상 결과:
-- 2024-12-24: 52개 (화)
-- 2024-12-25: 0개 (수, 휴장)
-- 2024-12-26: 49개 (목, 보유 종목만)
-- 2024-12-27: 0개 (금, 아직 미수집)
```

### 2. 시점별 데이터 일관성 확인
```sql
-- 특정 종목의 시계열 데이터 확인
SELECT 
    stock_code,
    date,
    close,
    volume,
    created_at
FROM daily_prices
WHERE stock_code = '005930'  -- 삼성전자
  AND date >= '2024-12-01'
ORDER BY date;

-- created_at 확인:
-- 모든 12/24 데이터의 created_at이 12/26 08:50경이어야 함
-- 모든 12/26 데이터의 created_at이 12/27 08:50경이어야 함
```

### 3. 백테스팅 데이터 품질 검증
```sql
-- 누락 날짜 탐지 (휴장일 제외)
WITH RECURSIVE dates(date) AS (
    SELECT DATE('2024-12-01')
    UNION ALL
    SELECT DATE(date, '+1 day')
    FROM dates
    WHERE date < DATE('2024-12-31')
)
SELECT 
    d.date,
    CASE strftime('%w', d.date)
        WHEN '0' THEN '일요일 (정상)'
        WHEN '6' THEN '토요일 (정상)'
        ELSE '⚠️ 누락 의심'
    END as status,
    COALESCE(COUNT(dp.stock_code), 0) as stock_count
FROM dates d
LEFT JOIN daily_prices dp ON d.date = dp.date
WHERE strftime('%w', d.date) NOT IN ('0', '6')  -- 주말 제외
GROUP BY d.date
HAVING stock_count = 0
ORDER BY d.date;
```

## 📝 향후 개선 사항

### 1. 공휴일 캘린더 추가
```python
# utils/korean_time.py에 추가 예정
KOREAN_HOLIDAYS = {
    '2025-01-01': '신정',
    '2025-01-28': '설날 연휴',
    '2025-01-29': '설날',
    '2025-01-30': '설날 연휴',
    '2025-03-01': '3·1절',
    # ... (추가)
}

def is_trading_day(dt: datetime) -> bool:
    """영업일 여부 확인 (주말 + 공휴일 체크)"""
    if dt.weekday() >= 5:  # 주말
        return False
    
    date_str = dt.strftime('%Y-%m-%d')
    if date_str in KOREAN_HOLIDAYS:  # 공휴일
        return False
    
    return True
```
